# Specs

## ID prefixes

**SP-R-001** — `ferrule spec id`, `spec next`, `spec refs` and `spec collisions` accept a spec ID whose prefix is 2 to 5 uppercase letters.

**SP-R-002** — `spec-delta` and `test-red` card events accept a spec ID whose prefix is 2 to 5 uppercase letters.

**SP-R-003** — PR and issue body assembly, the `## Spec changes since filing` section and the publish collision check included, recognise a spec ID whose prefix is 2 to 5 uppercase letters.
