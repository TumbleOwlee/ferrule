Read by `fe-checker` in scope `zoom-out`.

## Zoom-out check

Read both documents the brief names, then the project's code and its dependencies wherever a claim needs checking.

Write `## Reasoning`: per component and requirement, is it needed for the goal, could it be simpler, does existing code or a dependency already cover it.

A finding where the change is not needed, could be simpler, or is already covered by existing code or a dependency; each finding names what could be removed or what to reuse.
