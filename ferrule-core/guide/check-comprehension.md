# check-comprehension — Comprehension check of a brief and its architecture

Read by `fe-checker` in scope `comprehension`.

<!-- include: concise -->

## Comprehension check

Read only the two documents your brief names: `spec-diff.md` and `architecture.md`. A brief naming `spec-diff.md` `none` (a non-behavior run): `architecture.md` alone. Never open the code, another run file or an instruction file; never search.

Write `## Paraphrase`: in your own words, what the change proposes and how the existing system works.

A finding for each section you cannot paraphrase from the documents alone and each term they use without defining it.
